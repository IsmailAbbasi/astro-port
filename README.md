# astro-port

My personal portfolio and blog: a dark, minimal site built with **Astro** and the **EmDash** CMS, running on **Cloudflare Workers** (D1 + R2).

- Home: intro with CV download, latest posts, selected projects, tech stack
- Blog and project case studies, all edited in the admin at `/_emdash/admin`
- Content changes go live instantly, no rebuild

## Quick start

```bash
pnpm install
pnpm dev
```

Open http://localhost:4321/_emdash/admin to finish setup, then http://localhost:4321.

**Full instructions** (EmDash setup, editing content, deploying to Cloudflare, custom domain, troubleshooting): see **[SETUP.md](SETUP.md)**.
